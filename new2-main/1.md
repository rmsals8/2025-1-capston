데이터베이스 설계를 위해 필요한 주요 테이블과 필드들을 추천해드리겠습니다:

1. `Users` 테이블 (기본 사용자 정보)
- user_id (PK)
- email
- password (암호화)
- name
- phone_number
- created_at
- updated_at
- last_login_at
- is_active
- profile_image_url

2. `SocialLogins` 테이블 (소셜 로그인 연동)
- social_login_id (PK)
- user_id (FK)
- provider_type (KAKAO, NAVER 등)
- provider_user_id
- access_token
- refresh_token
- token_expires_at

3. `VisitHistory` 테이블 (방문 기록)
- visit_id (PK)
- user_id (FK)
- place_id
- place_name
- place_category
- visit_date
- rating (선택적 평점)
- review (선택적 리뷰)
- latitude
- longitude

4. `UserPreferences` 테이블 (사용자 선호도)
- preference_id (PK)
- user_id (FK)
- category_id (FK)
- preference_level (1-5)
- updated_at

5. `Categories` 테이블 (장소 카테고리)
- category_id (PK)
- category_name
- parent_category_id (계층구조를 위한)
- description

6. `SavedPlaces` 테이블 (찜한 장소)
- saved_place_id (PK)
- user_id (FK)
- place_id
- place_name
- place_category
- saved_at
- visit_planned_date (선택적)
- latitude
- longitude

7. `UserRecommendations` 테이블 (추천 기록)
- recommendation_id (PK)
- user_id (FK)
- place_id
- recommendation_type (SIMILAR, CATEGORY_BASED 등)
- recommended_at
- is_visited
- recommendation_score

8. `PasswordResets` 테이블 (비밀번호 재설정)
- reset_id (PK)
- user_id (FK)
- token
- expires_at
- is_used

추가 고려사항:
1. 모든 테이블에 soft delete를 위한 deleted_at 컬럼 추가 고려
2. 위치 데이터를 위한 공간 인덱스 사용
3. 카테고리는 계층구조 지원을 위한 설계 필요
4. 방문 기록과 추천을 위한 인덱스 최적화
5. 소셜 로그인 토큰 관리를 위한 보안 설계
6. 사용자 선호도 분석을 위한 집계 테이블 고려

이러한 구조로 설계하면 요구사항에 맞는 기능들을 효율적으로 구현할 수 있을 것입니다.

Flutter로 와이어프레임을 구현하기 위한 접근 방법을 분석해드리겠습니다:

1. 앱 구조 설계
- Provider 또는 Bloc 패턴 사용하여 상태 관리
- GetX를 활용한 라우팅 및 상태관리 고려
- 재사용 가능한 위젯 컴포넌트화

2. 페이지별 구현 전략:

홈 페이지:
- 상단 음성/텍스트 입력 섹션: TextField + 음성인식 버튼
- 최근 방문 장소: PageView 또는 ListView.builder로 캐러셀 구현
- 추천 장소: GridView로 구현
- 방문 희망 장소: ListView로 구현
- 하단 네비게이션 바: BottomNavigationBar 사용

경로 생성/추천 페이지:
- 상단 지도: Google Maps Flutter 패키지 활용
- 하단 경로 옵션: TabBarView로 여러 추천 경로 표시
- 경로 세부정보: ExpandableTile로 구현

내비게이션 페이지:
- 실시간 지도: Google Maps + 현재위치 트래킹
- 턴바이턴 안내: AnimatedPositioned로 상단 표시
- 하단 정보 패널: DraggableScrollableSheet 활용

설정 페이지:
- 각 섹션: ListView와 ListTile 조합
- 토글 설정: Switch 위젯 활용

3. 백엔드 연동 전략:

API 통신:
- Dio 패키지로 HTTP 통신 구현
- 인터셉터로 토큰 관리
- API 응답 모델 클래스 자동 생성 (json_serializable)

실시간 기능:
- WebSocket 연결로 실시간 위치 업데이트
- Stream으로 실시간 데이터 처리

로컬 데이터 관리:
- SharedPreferences로 설정 저장
- Hive로 오프라인 데이터 캐싱
- GetStorage로 빠른 데이터 접근

위치 서비스:
- Geolocator 패키지로 현재 위치 트래킹
- Background 위치 서비스 구현

4. 성능 최적화 고려사항:
- 이미지 캐싱 (cached_network_image)
- 리스트 아이템 lazy loading
- 위젯 리빌드 최소화
- 메모리 관리를 위한 dispose 패턴

5. 사용자 경험 개선:
- 스켈레톤 로딩 화면
- 부드러운 애니메이션 적용
- 오류 처리 및 피드백
- 오프라인 모드 지원

6. 보안 고려사항:
- 민감 정보 암호화 저장
- SSL 피닝
- 토큰 관리
- 앱 보안 정책 준수

- 위젯 테스트
- 통합 테스트
- 성능 테스트
- 사용성 테스트
